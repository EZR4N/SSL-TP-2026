# SSL 2026 - Trabajo Práctico y Ejercicios

Repositorio para la cursada de Sintaxis y Semántica de los Lenguajes.

## 📜 Reglas del Repositorio (Git Workflow)
Somos un equipo grande. Para no pisarnos el código:
1. **NUNCA** pushear directo a `master` o `development`.
2. Crea una rama para tu ejercicio: `git checkout -b feature/ejercicio-1-juan`
3. Sube tu rama y haz un Pull Request (PR) hacia `development`.
4. Al menos otro compañero debe revisar el código antes de mergear.
